## Versionamento automático (daqui pra frente)

Cada `installer\publish.ps1` gera:

| Onde | Formato | Exemplo |
|------|---------|---------|
| Versão numérica (Inno / assembly) | `yyyy.MM.dd.HHmm` | `2026.06.20.1811` |
| Descrição legível | `dd/MM/yyyy HH:mm` | `20/06/2026 18:11` |
| **Programas e Recursos** | `Traços 3D Studio (build 20/06/2026 18:11)` | via `AppVerName` |
| Propriedades do `.exe` | Descrição com data/hora do build | |
| Barra de status do app | `Build: 20/06/2026 18:11` | |
| `dist\last-build.txt` | Registro rápido do último build | |

Em `dotnet run` (dev) aparece **Build: desenvolvimento**.

## Como gerar de novo

```powershell
powershell -ExecutionPolicy Bypass -File installer\publish.ps1
```

Cada execução produz uma versão única por minuto — fácil de distinguir builds durante o desenvolvimento.
