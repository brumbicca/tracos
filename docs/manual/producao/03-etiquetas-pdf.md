# Traços 3D — Etiquetas PDF

**Última revisão:** 20/06/2026

---

## Neste artigo

- Gerar etiquetas individuais por peça
- Código curto, módulo, medidas e índice (ex.: 1/42)

---

## Exportar etiquetas

**Produção → Exportar etiquetas PDF...**

ou, na janela **Lista de peças**, botão **Exportar etiquetas PDF...**

1. Escolha o destino do arquivo.
2. O PDF contém uma etiqueta por peça (quantidade expandida — ex.: 2 laterais = 2 etiquetas).
3. Cada etiqueta inclui:
   - Nome do módulo e da peça
   - Medidas L × A × E
   - Material
   - Código curto para chão de fábrica
   - Numeração **índice / total**

---

## Quando usar

- Após validar a [lista de peças](./01-lista-de-pecas.md)
- Junto com o [plano de corte](./02-plano-de-corte.md) para separar e identificar peças na chapa
